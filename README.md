# 南京慢慢走

手机网站：<https://toomorr.github.io/nanjing-trip-2026/>

2026年10月2—6日南京旅行记录与剩余行程。10月4日已回填实际经历，4号中山陵下午场、5号总统府上午场与12:30富临轩午餐、6号南博上午场按用户最新反馈记录；5号红山与苗乡保留。公开页面不包含订单号、座位、证件、凭证或个人账号信息。

点击日期看当天卡片，点击地点名或地图标点对照位置。地图初始约占屏幕80%，随滚动缩到40%后固定，补偿空白维持正文正常滚动。单指默认阅读页面，开启“移动地图”后拖动；双指捏合、缩放按钮或触控板捏合用于缩放。

2—3号以实际经历为主，未确认完成的旧安排另作参考。4号玄武湖、台城和中华门保留为备选地图点，避免与中山陵预约冲突。旧日出补觉分支停用，不覆盖新预约。用户反馈的完成记录写入主数据，跨设备可见；自己点击○的标记仍只保存在当前浏览器，底部按钮清除本机标记。

导航按钮直接链接苹果地图，以名称和具体地址查找；地址面板也提供路线及复制地址。大众点评是已核对的具体门店链接；小红书搜索入口与已读公告在资料中区分。真实iPhone的Safari、微信内浏览器与App跳转需用户设备确认，手机尺寸预览不等同于真机验证。

底图为OpenStreetMap，点位统一WGS84。景区与楼宇点均有来源及入口说明；苗乡门店公开百度坐标只保留两位小数，经gcoord 1.0.7转成WGS84后仅表示片区范围，不能当作精确店门口。所有虚线都只是地点顺序示意。

天气为10月4日查询的中国天气网南京城区4—6日日间/夜间预报，非实时接口；超过12小时页面会提醒查看最新预报。网页刷新不改查询时间。未设置周期任务。

`trip-data.js`为主数据。修改后运行`node scripts/build-guide.cjs`同步[详细攻略](南京行程.md)。网站为静态文件，GitHub Pages从main根目录发布，`.nojekyll`避免额外构建。Leaflet 1.9.4本地文件及许可证见`lib/`，不依赖外部脚本CDN；地图底图仍需网络。
